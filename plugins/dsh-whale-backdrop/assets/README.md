# assets/ — 图片池

**这个目录就是配置。** 插件启动时扫这里的**顶层文件**（子目录不参与轮换），
把清单通过 `/plugins/dsh-whale-backdrop/images.json` 发给浏览器半边。

## 怎么用

1. 把你**有权使用**的图直接放进本目录：

   ```
   assets/
   ├── backdrop.jpg     ← 默认图：清单里的 primary，也是拿不到清单时的兜底
   ├── 别的图.webp
   └── 再来一张.png
   ```

2. 刷新 DSH 页面即生效（不用重建、不用重启）。
3. 支持 `jpg / jpeg / png / webp / avif`；多张图时每次刷新随机挑一张。

## 为什么这里是空的

本仓库**不分发图片**。原先开发时用的是第三方同人作品（Pixiv 上的画，版权归画师），
只在本机个人使用，不随仓库公开分发。

所以：**请自备图片**，并确认画师的授权范围（能否自用 / 改动 / 公开）。

- 一张图都没有也能正常用：插件照常加载，只是没有背景。
- 请不要把别人的作品提 PR 进本仓库。
